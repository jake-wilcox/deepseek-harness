# @deepseek-ai/dsh-client-ui-provider-usage

[English](README.md) | 中文

这个浏览器插件向 `conversation.composer.contextMeter.usage` 注册提供方账户额度内容；该 slot 是会话 ContextMeter 弹层中不感知具体提供方的子区域。打开弹层时，插件通过 `ctx.modelDirectories` 解析会话当前提供方，再调用提供方无关的 `llm.providerUsage` API。该分区把上下文占用与订阅额度明确分开，按提供方返回顺序显示每个周期，以及已用百分比、可选周期长度、可选重置时间、刷新状态和手动重试或刷新操作。

每个会话拥有一个私有读取器及身份稳定的可观察快照。读取器只在弹层贡献挂载期间发起网络工作；贡献关闭或会话 dispose 时会取消工作，并阻止陈旧结果提交。刷新失败时，最后一次成功结果会在该会话读取器的生命周期内保持可见；任何结果都不会进入共享会话状态或持久存储。不支持该能力的提供方会显示明确的不可用状态。

## 模型体验

无。插件只为浏览器呈现读取账户元数据，不会向模型请求加入内容、工具、设置或元数据。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与延期工作

- 用量刷新由用户打开 ContextMeter 或选择刷新操作触发；插件不会在后台轮询。
- 周期名称由提供方报告的时长派生。未报告时长的周期使用按位置生成的提供方无关标签。
